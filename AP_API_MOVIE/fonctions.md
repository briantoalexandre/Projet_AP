# Pour commenter et decommenter les lignes du proxy dans fonctions.php avec vscode

* appuyer sur Ctrl+F
* clicker sur Expression Regulière ou appuyer sur Alt+R
* chercher : //\$response
* appuyer sur la flèche puis remplacer par : $response
* ensuite chercher : \$response = f
* et remplacer par //$response = f
